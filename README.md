# OTT Streaming Content Trend Analysis

## Project Overview
This project focuses on analysing OTT streaming content available across Netflix, Hulu, Amazon Prime Video, and Disney+.

The objective is to explore content availability, release-year trends, audience age certifications, and Rotten Tomatoes ratings to identify useful patterns and business insights.

## Dataset
- Dataset: Movies on Netflix, Prime Video, Hulu and Disney+
- Source: Kaggle
- Total Records: 9,515
- Total Columns: 11

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Excel
- Google Colab

## Key Analysis Areas
1. Content availability across streaming platforms.
2. Movies released by year.
3. Rating comparison across platforms.
4. Age certification distribution.
5. Rotten Tomatoes rating distribution.
6. Content availability and overlap between platforms.

## Data Cleaning
- Checked missing values.
- Checked duplicate records.
- Removed unnecessary index column.
- Converted Rotten Tomatoes ratings into numeric format.
- Handled missing age certification values.
- Reviewed columns with limited analytical value.

## Deliverables
- Exploratory Data Analysis (EDA) notebook.
- Six or more data visualizations.
- SQL queries for core aggregations.
- Content Strategy Memo with three actionable insights.

## Conclusion
This project helps understand OTT content availability and rating trends across different streaming platforms. The analysis can support content strategy decisions and provide insights into streaming platform catalogues.
